# cck · 几猫 3A大作

浏览器里直接运行的第一人称射击游戏（单文件 HTML，Three.js）。

**在线游玩：**

- 第一人称版：https://itwake.github.io/cck/
- 第三人称版：https://itwake.github.io/cck/tps.html （越肩视角，可以看到背后的喷射器）

两个版本的标题页都有切换按钮。

## 操作

| 动作 | 键鼠 | 手机触屏 |
| --- | --- | --- |
| 移动 | `W` `A` `S` `D` | 左侧屏幕任意位置拖动（虚拟摇杆） |
| 视角 | 鼠标 | 右侧屏幕拖动 |
| 开火 / 瞄准 | 左键 / 右键 | “开火”（按住可拖动跟枪）/“瞄准” |
| 换弹 | `R` | “换弹” |
| 跳跃 | `Space` | “跳跃” |
| **喷射器起飞** | 空中再按 `Space` | 空中再点“跳跃”（按钮变为“喷射”） |
| **喷射器缓降** | 飞行中再按 `Space` | 飞行中点“缓降” |
| 切断中继 | 按住 `E` | 靠近中继后按住“交互” |
| 冲刺 / 蹲伏 | `Shift` / `C` | 摇杆推到最前方 / — |
| 暂停 | `Esc` / `P` | “暂停” |

## 喷射器

- 跳起后在空中再按一次跳跃，背后的双喷口点火，自动爬升到**第一高度（12 米）**并悬停。
- 飞行中水平机动更快；再按一次跳跃关闭推力，缓降落地（不会摔伤）。
- 燃料约可持续悬停 15 秒，耗尽后自动缓降；落地后自动回充。
- 准星左侧的仪表显示当前高度、第一高度刻度和剩余燃料。

## 手机

- 自动识别触屏并显示虚拟摇杆和按钮，画质自动切换为低档。
- 左下角半透明圆环是移动摇杆的位置（左半屏任意位置按下都可以），向上推即前进，推到底为冲刺。
- 安卓浏览器点“开始行动”会进入全屏并锁定横屏。
- iPhone：Safari 里点“分享 → 添加到主屏幕”，从主屏幕图标打开即可全屏游玩；建议横屏。
- 触屏排查：打开 https://itwake.github.io/cck/?touchdebug ，屏幕中间会显示触点编号、摇杆状态和移动量。

## 文件

- `index.html` — 第一人称版（含喷射器与手机适配）。
- `tps.html` — 第三人称版：同一套游戏代码，摄像机在角色右肩后方（贴墙时自动拉近，瞄准时拉近），子弹沿准星方向射出，曳光弹和枪口火焰来自角色手中的步枪。
